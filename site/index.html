Adding events

  • Everything comes from the parish Google Calendar. Changes appear within about 15 minutes; to publish straight away open the deploy workflow and press Run workflow.
  • Repeating events show on every date, and the What's On page shows them once with the pattern ("Second Monday of each month").
  • Posters / header images: in the event, choose Add attachment and pick an image or PDF from Google Drive. The file must be shared as Anyone with the link. The first image (or the first page of the first PDF) becomes the picture; events with a picture appear in the banner and on the What's On page. PDFs and other files are listed as downloads.
  • Description: bold, italics, lists and links from the Google Calendar editor are kept. Email addresses and phone numbers become clickable and are shown in a Contact box.
  • Location: full addresses get a map link.
  • Hiding events (room bookings, rehearsals): set the event's visibility to Private in Google Calendar.
